# 매수 후보와 보유·청산 가이드

지지·반등 조건에 맞는 매수 후보를 찾고, 실제 매수·매도 체결을 등록하여 보유·익절·손절 계획을 확인하는 Streamlit 앱입니다.

화면 버전은 `TRADE-DESK-1`, 매수 전략 버전은 `SUPPORT-REBOUND-1`입니다.

## 기본 사용

### 오늘의 매수 후보

1. 사이드바에서 총 계좌 잔고와 한 번에 허용할 손실률을 설정합니다.
2. **매수 후보 찾기**를 누릅니다. 조건부 진입 후보와 관찰 후보를 각각 상위 5개부터 보여줍니다.
3. 후보를 선택하고 **이 종목의 매매 계획 보기**를 누릅니다. 같은 화면에서 진입 트리거·상한가·수량·익절 목표·손절가를 확인합니다. 종목명이나 코드로 직접 조회할 수도 있습니다.
4. 실제 매수한 경우에만 **이 종목의 매수 체결 입력**으로 이동하여 실제 가격·최초 수량·날짜·최초 손절가를 저장합니다. 후보 선택이나 계획 열람만으로 보유에 추가되지 않습니다.

등록 보유분의 예상 손절 위험은 다음 매수 수량 계산에 반영합니다. 미등록 보유분의 위험은 사이드바에서 별도로 입력할 수 있습니다.

### 내 보유종목 관리

- 등록된 실제 체결과 확정 일봉으로 보유 유지·부분 익절·손절·추세 이탈·보유 기한에 따른 청산을 안내합니다.
- 목표가에 도달해도 실제 매도를 자동 기록하지 않습니다. **실제 매도 체결 기록**에서 체결을 저장해야 잔여 수량과 익절 단계가 바뀝니다.
- 권장 보호선은 자동으로 적용하지 않습니다. 증권사에서 손절가를 설정한 뒤 변경 내역을 기록합니다. 손절가는 낮출 수 없습니다.
- 추가 매수분은 별도의 매수 기록으로 등록합니다. 마지막 매도 입력을 잘못 저장했다면 취소할 수 있습니다.
- 보유·체결·손절 변경 내역은 브라우저 세션에 보관됩니다. 새로고침이나 서버 재시작 전에 **보유 내역 백업 다운로드**를 사용하세요. 다음 세션에서 백업 파일을 복원할 수 있습니다. 파일은 보유·체결 정보를 포함하므로 본인이 보관합니다.

## 안내 기준

확정 일봉을 사용하여 다음 거래일의 행동을 계획합니다. 당일 봉은 15:40 KST 이후 실제 조회한 데이터부터 사용합니다. 장중 손절 감시와 실제 체결 확인은 증권사에서 해야 하며 이 앱은 계좌를 자동 조회하거나 주문하지 않습니다.

익절 목표는 실제 매수가와 최초 손절가 사이의 가격 차이인 R을 기준으로 정합니다. 1R에서 최초 수량의 약 30%, 2R에서 약 40%, 3R에서 나머지를 청산하는 계획입니다. 정수 주식 수량으로 나누며 소량은 최소 1주를 사용합니다. 비용 추정은 매수 0.05%·매도 0.20%를 기본 가정합니다. 실제 비용과 갭 손실은 다를 수 있습니다.

시장 위험 회피나 필수 데이터 미확인 상태에서는 새 매수를 보류합니다. 가격·체결 정보가 부족하면 보유 내역을 유지하면서 안내를 보류합니다.

## 고급 분석

사이드바의 **고급 분석 보기**를 켜면 단일 종목 백테스트, 다종목 포트폴리오, WFO·슬리피지 검증을 선택할 수 있습니다. 기본 매매 흐름에는 필요하지 않습니다. 검증 결과는 실전 수익성을 보장하지 않습니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

시세와 종목 목록은 외부 제공처를 이용합니다. 네트워크나 제공처 문제로 목록을 가져오지 못하면 스캔 완료로 표시하지 않습니다.

## 회귀 검증

```bash
python -m unittest discover -s tests -q
```

금융 엔진과 사용자 흐름을 합성 데이터로 검증하며 API 키나 외부 네트워크가 필요하지 않습니다. 변경 근거와 검증 범위는 [CODE_REVIEW.md](CODE_REVIEW.md)에 기록합니다.
